# 接口开发平台（API Builder）

## 功能定位

API Builder 将参数化 SQL 配置为 REST 接口。接口密钥只用于调用这类动态接口，不代表后台用户，也不能换取后台 JWT。

## 接口密钥

- 一个厂商或业务应用拥有一个接口密钥。
- 一个密钥可以被授权访问多个指定的 SQL 接口。
- 未明确授权的接口默认拒绝访问。
- 完整密钥仅在创建或重新生成时展示一次，数据库只保存带 Pepper 的 HMAC-SHA256 摘要。
- 默认有效期为 180 天，支持禁用、重新生成和调整接口授权。

调用受保护接口时只接受：

```text
X-API-Key: <api_key>
```

不支持 Query 参数、Bearer API Key 或 `/auth/api-token`。

## 调用校验

请求进入 SQL 执行器前依次校验密钥、状态、有效期、接口授权和每分钟限流。接口调用记录关联密钥与接口，但不保存完整密钥或敏感请求参数。

## SQL 安全

SQL 参数使用 `:paramName` 占位符并通过 Sequelize 参数绑定。系统仅允许 SELECT、INSERT、UPDATE、DELETE，禁止 DROP、TRUNCATE、ALTER、CREATE、GRANT、REVOKE 和多语句执行。

## 管理端

“接口密钥”页面负责创建调用方、选择多个授权接口、查看状态和最后使用时间。接口列表中的调用说明只展示 `X-API-Key` 调用方式，授权关系使用同一数据源。

## 注意事项

- SQL 接口直接访问数据库，授权范围应遵循最小权限原则。
- 写操作必须使用参数绑定并配置严格的业务条件。
- `require_auth: false` 会公开接口，只应使用于确认无敏感数据的场景。
