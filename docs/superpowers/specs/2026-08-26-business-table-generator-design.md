# 代码生成器业务建表设计

## 目标

允许管理员在代码生成器中通过可视化表单创建新的业务数据表，并在建表成功后自动初始化代码生成配置、进入配置维护流程。第一版只支持新建表，不支持修改或删除已有表。

同时将接口密钥创建与编辑弹窗中的原生日期输入替换为项目统一的 `DatePicker` 组件。

## 范围与约束

- 新建表必须使用 `biz_` 前缀，用户只填写表名后半部分。
- 禁止通过此功能修改、重命名、清空或删除任何已有表。
- 禁止前端提交或执行原始 DDL。
- 表名和字段名只允许小写字母、数字和下划线，且必须以字母开头。
- 不允许创建与现有表重名的业务表。
- 建表权限沿用代码生成器的创建权限。

## 用户流程

1. 用户在代码生成器的“数据库表”页点击“新建业务表”。
2. 在弹窗中填写表名后缀、表注释，并添加业务字段。
3. 字段可配置名称、注释、类型、长度或精度、是否必填、默认值、唯一约束和普通索引。
4. 系统展示最终表名，例如 `biz_customer`，并在提交前完成前后端校验。
5. 后端在事务中创建业务表、约束及索引。
6. 建表成功后自动调用现有模块配置初始化能力。
7. 前端刷新表列表，并直接打开该模块的生成配置弹窗。

## 支持的字段类型

第一版只开放后台管理常用类型，并由后端映射到 PostgreSQL：

- `string`：`VARCHAR`，长度 1–2000，默认 255。
- `text`：`TEXT`。
- `integer`：`INTEGER`。
- `bigint`：`BIGINT`。
- `decimal`：`DECIMAL(precision, scale)`，精度和小数位受限校验。
- `boolean`：`BOOLEAN`。
- `date`：`DATE`。
- `datetime`：`TIMESTAMP WITH TIME ZONE`。
- `json`：`JSONB`。

不开放自定义 SQL 类型、表达式默认值、外键、触发器和存储过程。默认值必须与字段类型匹配；日期时间只允许系统定义的“当前时间”选项。

## 自动字段

每张业务表由后端自动添加以下字段，前端不能覆盖：

- `id`：UUID 主键，默认生成 UUID。
- `created_by`、`updated_by`、`deleted_by`：可空 UUID。
- `created_at`、`updated_at`：非空时间戳，默认当前时间。
- `deleted_at`：可空时间戳，用于软删除。

业务字段不得与自动字段重名。至少需要一个业务字段。

## 后端设计

在现有 generator 模块中增加独立的业务建表服务，职责仅包括：

- 校验并规范化表与字段定义。
- 检查目标表是否已存在。
- 使用 Sequelize QueryInterface / QueryGenerator 根据白名单配置生成 DDL。
- 在单个数据库事务内创建表、唯一约束与索引。
- 调用现有 `module-config.service` 初始化生成配置。
- 返回新表信息及已初始化的模块配置。

新增接口：

`POST /api/generator/business-tables`

请求体包含表名后缀、表注释和业务字段数组。接口返回最终表名和模块配置。路由要求登录并校验 `generator:create` 权限。

如果建表或配置初始化任一步失败，事务整体回滚，不保留半完成表。重名、非法标识符和不支持的类型返回明确的 400 或 409 错误。

## 前端设计

在 `TablesSection` 工具栏增加“新建业务表”按钮，并新增业务建表弹窗：

- 顶部展示不可编辑的 `biz_` 前缀与表名后缀输入框。
- 字段配置使用可增删、可排序的紧凑列表。
- 类型变化时只展示相关配置，例如字符串长度或小数精度。
- 自动字段只作为说明展示，不进入可编辑字段列表。
- 提交期间禁用重复操作。
- 成功后关闭建表弹窗、刷新表列表，并打开现有配置弹窗。

接口密钥弹窗中的有效期字段使用现有系统 `DatePicker`，保持当前字符串值和接口提交格式不变。

## 验证重点

- 非 `biz_` 表无法通过该接口创建。
- 非法标识符、重复字段、保留字段和不支持类型被拒绝。
- 同名表返回冲突错误，不影响已有表。
- DDL 失败或配置初始化失败时没有残留表。
- 成功响应包含模块配置，前端能直接进入配置维护。
- 日期选择不再调用浏览器原生日期控件。

## 非目标

- 修改、删除、重命名已有表。
- 导入 DDL 或执行用户输入的 SQL。
- 可视化外键关系设计。
- 数据迁移、表结构版本管理和回滚历史。
- 自动生成并立即发布代码；用户仍需确认生成配置后再执行生成。
